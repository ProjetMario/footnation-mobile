# Flag textures

Bundled PNG textures rendered from the 4:3 SVG flags in flag-icons 7.5.0, by lipis and contributors (MIT).
Source: https://github.com/lipis/flag-icons/tree/v7.5.0/flags/4x3

Rendered at 256 × 192 with sharp. The Home football uses one flag per complete rotation, in the order defined in src/lib/ballNations.ts. No runtime network request is required.
