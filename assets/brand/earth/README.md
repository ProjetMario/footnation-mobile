# Earth land outlines

Simplified longitude/latitude land rings from world-atlas 2.0.2 `land-110m.json`, derived from Natural Earth 1:110m public-domain data. world-atlas is MIT licensed (see LICENSE.txt).

Source: https://github.com/topojson/world-atlas/tree/v2.0.2
Natural Earth: https://www.naturalearthdata.com/

Topology arcs are decoded and coastline vertices simplified with a 0.55-degree Ramer–Douglas–Peucker tolerance for the 34px navigation globe. No network request is made at runtime.
